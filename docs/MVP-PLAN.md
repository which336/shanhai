# 《山海拾遗录》MVP 拆分计划

> 目标：**两周（10 个工作日）** 内做出一个可玩切片  
> 引擎：Godot 4.x（GDScript）  
> 配套设计：见 `docs/GDD-山海拾遗录.md`
>
> **状态：原型 v0.5.4 已完成，原计划范围全部超额。详见底部「实际完成」章节。**

---

## 一、MVP 范围（明确"做什么 / 不做什么"）

### ✅ 做（Must-have）


| #   | 内容                                      | 说明                 |
| --- | --------------------------------------- | ------------------ |
| M1  | 主菜单 → 单区域跑图 → 战斗 → 结算 → 回菜单             | 完整闭环               |
| M2  | 1 个可玩角色：方寻                              | 起手卡组固定 8 张         |
| M3  | 24 张卡（8 起手 + 16 池子）                     | 数据驱动（`.tres`）      |
| M4  | 4 种敌人 + 1 个精英 + 1 个 BOSS（毕方）            | 含意图系统              |
| M5  | 节点地图（10~12 节点）：战斗 / 精英 / 商人 / 休整 / BOSS | 当前先不做事件节点          |
| M6  | 唤醒小游戏（击败 BOSS 后选译文）                     | 核心创新点必须有           |
| M7  | 山海图鉴（解锁过的卡可在菜单查看原文+译注）                  | 文化传承的最小可见落地        |
| M8  | 简易存档（JSON）                              | 仅记录已解锁图鉴 + meta 进度 |


### ❌ 不做（Out-of-scope，留到 v0.6+）

- 多角色（阿离、燧）
- 五大区域（仅做南山·朱雀庭）
- 回响事件 / 商人之外的剧情节点
- 神器系统（被动道具）
- 多结局 / 终局 BOSS
- 音乐音效（先用占位静音）
- 美术成品（用纯色块 + 文字占位即可，不阻塞玩法验证）

### 验证目标

**做到能让一个完全没看过 GDD 的人，5 分钟内理解"啊，这是一个用山海经卡片打牌的肉鸽，越懂典籍卡组越强"。**

## 二、十日里程碑

### Day 1 · 项目骨架（基础设施）

- `project.godot` + 目录结构 + `.gitignore`
- Autoload：`GameState`、`RunState`、`CardDatabase`
- 数据资源类：`Card`、`CardEffect`、`EnemyData`、`CodexEntry`
- README + 入口场景（黑屏跳转测试）
- 验收：双击 `project.godot` 能在 Godot 中打开，F5 不报错

### Day 2 · 战斗系统骨架

- `BattleManager`：抽牌 / 弃牌 / 重洗 / 灵韵
- `TurnManager`：玩家阶段 / 敌方阶段切换
- `Player`、`Enemy` 节点：HP / 护盾 / 状态
- 单元测试：写一个最小用例确保起手 4 张、出一张消耗灵韵、第二回合摸 2 张
- 验收：在编辑器里点"开始战斗"按钮，能看到牌出现、点卡能消耗（哪怕是文字 UI）

### Day 3 · 战斗 UI 与可视化

- 卡牌 UI（`Control` + 简单背景 + 标题 + 描述 + 费用）
- 手牌排列动画（弧形排列）
- 拖拽出牌到敌人 / 玩家
- 敌方意图图标显示（"将攻击 X" / "将获得 Y 护盾"）
- 伤害飘字 / 护盾变化动画
- 验收：玩家能用鼠标拖卡打敌人，看到血量变化

### Day 4 · 卡牌效果系统 + 数值

- 效果原子：DAMAGE / BLOCK / DRAW / GAIN_ENERGY / APPLY_STATUS / HEAL
- 状态效果：灼焰（每回合掉血）/ 湿润（受伤+1）/ 根脉（每回合护甲+2）
- **流派共鸣**：本回合内同流派卡 ≥3 张时触发 buff
- 用占位卡表（5 张）跑通整套
- 验收：占位 5 张卡的所有效果在战斗中都能正确生效

### Day 5 · 24 张首发卡 + 4 敌人 + 毕方 BOSS

- 卡表灌入 `data/cards/*.tres`（含山海经原文、白话）
- 敌人数据 `data/enemies/*.tres` + 行动模式（脚本化）
- BOSS 毕方：3 阶段（独足跳跃 / 引火焚林 / 衔木冲刺）
- 验收：能用初始卡组完整打过一场遭遇战 + 一场 BOSS

### Day 6 · 肉鸽地图

- 节点图生成（确定 7 行 × 3-4 列结构，参考 STS）
- 节点类型：战斗 / 精英 / 商人 / 休整 / BOSS
- 玩家在节点间移动（点击下一行的可达节点）
- 进入对应场景，结算后回到地图，节点标记已通过
- 验收：从开始到 BOSS 能走完一整局

### Day 7 · 唤醒小游戏 + 商人 + 休整

- 击败 BOSS / 精英时进入"唤醒"界面：显示原文 + 4 段译文，选对得唤醒卡
- 商人界面：3 张卡 + 2 个抹除/升级服务
- 休整界面：恢复生命 30% 或 升级一张卡（卡牌+号 = 数值更强）
- 验收：唤醒选对 / 选错 都有不同的产物，进入下一节点

### Day 8 · 山海图鉴 + 存档

- 图鉴菜单：列出所有已解锁卡，点击查看大图 + 原文 + 译注 + "今天活在哪里"
- 存档：JSON 写到 `user://save.json`，记录解锁图鉴 ID 集合 + meta 货币（典籍碎片）
- 主菜单显示当前进度
- 验收：通关一次后退出再进，图鉴里那场战斗见过的卡都已解锁

### Day 9 · 串联打磨 + 平衡

- 走 5~10 把完整流程，记录手感问题
- 调数值：BOSS 难度、卡费、敌人 HP
- 修必现 bug
- 加最基础的视觉反馈（伤害震屏、卡牌进出场补间）
- 验收：能不退出地完整跑 1 把

### Day 10 · 文档 + 演示

- 录一段 3 分钟通关演示（OBS 或 Godot 内置）
- 更新 README 截图
- 写 `CHANGELOG.md`
- 标 git tag `v0.1-mvp`
- 验收：把 build 给一个朋友玩 30 分钟，记录他的反应

## 三、按文件粒度的任务清单

### 数据（`data/`）

- `data/cards/`：24 个 `.tres`
- `data/enemies/`：5 个 `.tres`（4 小怪 + 毕方）
- `data/codex/codex.json`：图鉴元数据汇总（原文、译文、考据来源、今日存续）

### 脚本（`scripts/`）

- 核心
  - `core/game_state.gd`（Autoload，玩家全局状态：解锁的图鉴、典籍碎片）
  - `core/run_state.gd`（Autoload，本局状态：当前 HP、灵韵、当前卡组、地图位置）
  - `core/save_system.gd`（JSON 读写，签名校验防手改也可以做但 MVP 不必）
- 卡牌
  - `card/card.gd`（`Resource`，卡牌定义）
  - `card/card_effect.gd`（`Resource`，可叠加的效果原子）
  - `card/deck.gd`（抽 / 弃 / 消耗堆）
  - `card/card_database.gd`（Autoload，启动时扫描 `data/cards/` 并加载）
- 战斗
  - `battle/battle_manager.gd`（场景脚本）
  - `battle/turn_manager.gd`
  - `battle/player.gd`
  - `battle/enemy.gd`
  - `battle/enemy_data.gd`（`Resource`）
  - `battle/status_effect.gd`
- 地图
  - `map/map_generator.gd`
  - `map/map_node.gd`
- UI
  - `ui/card_view.gd`（卡牌 Control）
  - `ui/hand_layout.gd`
  - `ui/codex_view.gd`
- 唤醒
  - `awaken/awaken_view.gd`

### 场景（`scenes/`）

- `main_menu.tscn`
- `battle/battle.tscn`
- `battle/card_view.tscn`
- `map/map.tscn`
- `shop/shop.tscn`
- `rest/rest.tscn`
- `awaken/awaken.tscn`
- `codex/codex.tscn`
- `result/result.tscn`

## 四、最小可玩切片（Day 5 末，最早能"玩"的版本）

## 六、风险与对策


| 风险                 | 对策                                 |
| ------------------ | ---------------------------------- |
| 卡牌效果系统过早抽象，反而难加新效果 | MVP 阶段允许"硬编码 if-else"，等 30+ 张卡后再重构 |
| 美术拖累节奏             | 全程占位 ColorRect + 文字。最终美术单独成迭代      |
| 平衡反复改              | MVP 不追求平衡，能玩通就行；正式版再调              |
| Godot 4 / 3 语法混淆   | **统一用 Godot 4.x**，禁用 3.x 教程粘贴      |

- 四种小怪原型明确为迷雾狐裔 / 赤狐、鹿蜀、从从、类；鹿蜀已按白头马身、身有虎纹、红尾特征重做
- `R` 键重置地图加入确认流程，并同步清零角色等级与经验
- 小地图移动到更靠左上角，并重点标出玩家与三名 BOSS 的位置
- 清理旧 SVG 贴图体系、下载源素材、未使用职业贴图和空文件夹
- README、GDD、MVP 计划与 `CHANGELOG.md` 统一记录当前版本状态
### 原 MVP 全部完成

- M1：完整闭环（主菜单 → 地图 → 战斗 → 结算 → 回菜单）
- M2：方寻角色 + 起手 8 张卡
- M3：24 张卡（数据驱动改用 JSON 而非 .tres，更便于策划）
- M4：4 小怪 + 1 精英 + BOSS
- M5：节点地图（升级为 96×60 顶视角探索）
- M6：唤醒小游戏
- M7：山海图鉴
- M8：简易存档

### 在 MVP 之外加做的内容（用户驱动需求）

1. **大型 Roguelike 探索地图**（96×60，相机跟随，小地图）
2. **像素风视觉**（草地纹理、8×8 角色 sprite、idle 浮动动画、椭圆阴影）
3. **平滑连续移动**（220 px/s，分轴碰撞，撞墙顺滑）
4. **小怪 AI**（漫游 / 7 格内追击）
5. **即时战斗**（接触自动互殴）
6. **经验等级系统**（升级满血 + max_hp +10）
7. **三档 BOSS**（弱/中/强 HP 70/110/160）
8. **等级影响卡牌战斗**（Lv≥3 +1 灵韵；Lv≥5 +1 抽牌；Lv≥7 +1 灵韵）
9. **通关进度**（3 BOSS 累计，差异化奖励）
10. **山海宝匣**（10 选 1 随机奖励）
11. **回响事件**（6 个剧情，3 选 1，含获得卡牌）
12. **文化片段**（自动拾取 +EXP +碎片）
13. **古玩铺**（真正商店：3 张随机卡 + 回血 + +max_hp）
14. **K 键随时打开图鉴**（关闭后回地图，进度不丢）
15. **BOSS 战规则调整**：不再强制所有卡一次性；普通卡进入弃牌堆并循环，只有写明“消耗”的卡才进入消耗堆
16. **程序合成音频**（AudioStreamGenerator 实时合成 8-bit BGM + 12 种 SFX，三角波柔和化 + 节流去刺耳）
17. **小地图 Tab 切换**
18. **R 键当场重生地图**
19. **手牌多行布局**（HFlowContainer，卡牌再多也能完整看到/点到，不再被切到屏外）
20. **卡牌战斗规则定型**：战斗开始起手 4 张；第 2 回合起每回合追加摸 2 张；回合结束保留未使用手牌；普通出牌进弃牌堆并循环洗回，只有写明“消耗”的卡进消耗堆
21. **卡牌交互稳定性修复**：出牌按手牌位置结算，战斗牌堆初始化时复制独立卡牌实例；修复抽卡牌第二回合无响应、同名基础牌误删多张、点击文字区域不响应等问题
22. **自动化回归测试增强**：`tests/test_smoke.gd` 增加卡牌交互专项，覆盖抽卡牌消失并抽牌、第二回合抽卡牌可结算、同名基础牌只移除一张
23. **无牌兜底回流**：若长战斗中手牌 / 抽牌堆 / 弃牌堆都为空，会把消耗堆洗回抽牌堆，避免玩家进入无牌软锁
24. **版本与文档同步**：项目应用版本、Windows 导出资源版本、主菜单显示、README、GDD 与 MVP 计划统一到 v0.5.4
25. **双视角探索模式**：顶距 / 等距视角可切换，图鉴返回保持视角状态，两个视角共用移动、碰撞和实体数据
26. **等距地图可读性优化**：地面、石块围墙、深度排序、遮挡关系、可行走区域、玩家定位光环和实体脚点完成一轮修正
27. **山海经实体美术替换**：小怪、穷奇精英、BOSS、宝箱、狐面老者商店、驿站、事件石碑、文化碎片均有顶距 / 等距图集
28. **异兽原型校准**：迷雾狐裔 / 赤狐、鹿蜀、从从、类、穷奇按文字原型进行轮廓和特征迭代
29. **地图交互修正**：R 键重置加入确认框，重置时清空等级和经验；小地图更靠左上角并重点标出玩家与 BOSS
30. **资源清理**：删除旧 SVG 贴图体系、下载源素材、未使用 archer/wizard 贴图和空目录
