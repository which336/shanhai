# 山海拾遗录 · Shanhai: Echoes of the Lost Realms

> 一款 **Roguelike 顶视角探索 + 卡牌构筑 + 轻叙事 RPG + 山海经文化** 的 Godot 单机游戏（原型 v0.5.4）
> **核心理念**：唤醒，而非消灭。少年方寻在被「忘川之雾」侵蚀的山海回响之地，用古籍中的记载逐一**唤醒**沦为暴戾的异兽，让被遗忘的中华文化重新被看见。

## 当前可玩内容（原型 v0.5.4）

### 一局完整流程
```
主菜单 ──[开始冒险]──▶ 96×60 大型像素探索地图（每局随机生成）
                       │
                       ├─ WASD 平滑移动 + 相机跟随 + 小地图（Tab 切换）
                       │
                       ├─ 小怪「兽」  ─ 即时碰撞战斗（自动互殴）
                       │                ↑ 击杀给 EXP，等级提升 max_hp+10
                       │
                       ├─ 文化片段「片」 ─ 自动拾取 +5 EXP +1 碎片
                       │
                       ├─ 山海宝匣「宝」 ─ 弹奖励面板（10 选 1：碎片/EXP/卡/血/+max_hp）
                       │
                       ├─ 回响事件「录」 ─ 弹剧情面板（精卫衔木 / 扶桑朝露 等 6 个，3 选 1）
                       │
                       ├─ 古玩铺「市」  ─ 弹商店面板（3 张随机卡 / 回血 / 永久 +5 max_hp）
                       │
                       ├─ 讲古驿站「歇」 ─ 回 25 气血
                       │
                       ├─ 精英「奇」    ─ 卡牌回合战斗 + 唤醒小游戏（选译文得唤醒卡）
                       │
                       └─ 三个 BOSS：
                            「弱」雏火·毕方   HP 70   卡牌战斗
                            「中」讹火·毕方   HP 110  卡牌战斗
                            「强」焚岭古毕方  HP 160  卡牌战斗

                       通关条件：击败全部 3 个 BOSS = 全境净化
```

### 三大子系统

#### 1. 顶视角 Roguelike 探索
- 96×60 像素网格地图（每格 48 px，世界 4608×2880）
- 支持 `V` 在顶距 / 等距两种探索视角之间切换，移动、碰撞和实体位置共用同一套地图数据
- 每次开局完全随机：岩石分布、敌人/宝物/事件位置全部不同
- 像素风草地（5 层细节）+ 立体岩石
- 小地图（左上 288×180）实时显示玩家、3 个 BOSS、精英、视野框；玩家与 BOSS 使用重点标记
- Tab 切换小地图显隐
- BFS 联通性保证：不会有困死实体
- 玩家、小怪、精英、BOSS、宝箱、商店、驿站、事件与碎片均已替换为顶距 / 等距两套山海经风格图集
- 等距模式包含玩家脚下定位光环、实体脚点锚定、深度排序、墙体遮挡和更清晰的可行走区域表现

#### 2. 即时战斗 + 等级
- 玩家与小怪靠近自动互殴（不需要按键）
- 玩家攻击：每 0.45 秒造成 `3 + level/2` 伤害
- 小怪自带 AI：玩家 7 格内主动追击；7 格外漫游
- 击杀小怪给 5+ EXP，升级满血 + max_hp+10
- **等级提供卡牌战斗加成**：Lv≥3 +1 灵韵/回合，Lv≥5 +1 每回合摸牌，Lv≥7 再 +1 灵韵 → 鼓励先刷小怪、再战 BOSS

#### 3. 卡牌构筑（仅 BOSS / 精英）
- 24 张首发卡，三大流派：
  - **山经守拙**（防御 / 草木）
  - **海经灵动**（速度 / 水族）
  - **荒经锐意**（爆发 / 凶兽）
- 每张卡都附《山海经》原文 + 白话译注 + 「今天还活在哪里」（戏曲、地名、纹样、品牌）
- **战斗节奏（保留手牌模式）**：
  - 战斗开始起手 4 张牌
  - 第 2 回合起，每回合开始追加摸 2 张牌（Lv≥5 时 +1）
  - 灵韵 3 点/回合（等级 ≥3 时 +1，≥7 时再 +1）
  - 回合结束不会丢弃未使用手牌，玩家可以攒牌规划下一轮
  - 抽牌堆抽完时弃牌堆自动洗回
- **同流派出 ≥ 3 张/回合 = 触发"流派共鸣"**（额外护盾/抽牌/强化）
- **BOSS 战规则**：普通卡进入弃牌堆并循环；只有写明“消耗”的卡才进入消耗堆，避免长战斗中整副牌被打空
- **手牌 UI**：自动多行换行（HFlowContainer），卡牌再多也能完整看见 / 点到
- **卡牌交互稳定性**：出牌按手牌位置结算，卡牌实例在战斗中独立复制；解决同名基础牌误删多张、抽卡牌第二回合无响应、点击区域被文字控件拦截等问题
- **唤醒小游戏**：击败精英/有图鉴 BOSS 后，给出原文 + 4 段译文，选对得到唤醒卡（永久入卡组）

#### 4. 像素风音频（程序合成，无需外部素材）
- AudioStreamGenerator 实时合成 8-bit 风格 BGM（主菜单 / 地图 / 战斗 三套旋律）
- AudioStreamWAV 即时合成 SFX：点击 / 攻击 / 受伤 / 拾取 / 升级 / 商店购买 / 战斗开始 / 胜利 / 死亡 / 出牌 / 消耗

## 操作指南

### 探索地图
| 按键 | 功能 |
| --- | --- |
| **WASD / ↑↓←→** | 移动（平滑连续，支持斜向） |
| **Tab** | 切换小地图显隐 |
| **K** | 打开山海图鉴（关闭后回到地图，进度不丢） |
| **R** | 当场重新生成本层（测试用） |
| **ESC** | 在地图上 = 回主菜单；在战斗中 = 放弃这场战斗 |
| 走到节点格 | 自动弹对话框 / 自动拾取 / 自动战斗 |

### 卡牌战斗
| 操作 | 说明 |
| --- | --- |
| 点击手牌 | 出牌（自动选第一只敌人） |
| 「结束回合」 | 进入敌方阶段 |
| 「返回」/ ESC | 放弃这场战斗，节点不会消失 |

- 直接按 **F5**

## 主流价值观与红线

- **唤醒，不是消灭**：核心机制是"读懂典籍才能获得最强奖励"，鼓励理解而非战胜
- 不渲染暴力血腥（伤害用"灵韵流散"等表现）
- 山海经原文以《山海经校注》（袁珂）为底本，每条目标注出处篇目
- 不出现宗教/玄学误导
- 单机买断模式，不设氪金抽卡
- 每张卡都有「今天活在哪里」字段（戏曲、纹样、地名、卫星名等），把游戏关进现实

## 数据驱动 · 如何加内容

### 加新卡
编辑 `data/cards/cards.json`，按现有格式追加：
```json
{
  "id": "shan.new_card",
  "title": "卡名",
  "school": 1,            // 0=通用 1=山经 2=海经 3=荒经
  "card_type": 0,         // 0=攻击 1=法术 2=持续
  "rarity": 0,            // 0=凡品 1=珍品 2=神品 3=遗珍
  "cost": 1,
  "requires_target": true,
  "description": "造成 {0} 点伤害。",
  "classic_quote": "山海经原文...",
  "translation": "白话译注...",
  "alive_today": "今天活在哪里...",
  "effects": [
    { "kind": 0, "amount": 6, "target": 1 }
  ]
}
```

### 加新事件
编辑 `data/events/echo_events.json`：
```json
{
  "id": "...",
  "name": "事件名",
  "story": "故事描述...",
  "options": [
    {"label": "选项 A", "type": "card", "card": "shan.xxx", "preview": "获得：xxx"},
    {"label": "选项 B", "type": "fragments", "amount": 30, "preview": "+30 碎片"},
    {"label": "选项 C", "type": "heal", "amount": 20, "preview": "+20 气血"}
  ]
}
```

支持的 `type`：`card / card_cost / fragments / exp / heal / heal_full_cost / max_hp / max_hp_cost`。

### 加新敌人
编辑 `data/enemies/enemies.json`，参考现有的 BOSS 字段（含 awaken_options / awaken_card_id 用于唤醒小游戏）。
